# Macbook Setup

Setup for my new Mac.

## Get Started

### Install Apps in App Store

- Xcode

```sh
xcode-select --install
```
### [Homebrew](https://brew.sh/) and Others

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
